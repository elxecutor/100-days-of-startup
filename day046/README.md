# 20 Actionable Startup Incubation Steps — Embedded in the SaaS

## How the SaaS Answers All 20 Questions

| Step | Question | Where in the SaaS |
|------|----------|-------------------|
| 1 | Define core problem | Landing page hero: "$30k tools lock your machine" + hoverable pain points |
| 2 | Identify target segment | Pricing page (4 segments) + Landing page "Customer Segments" section |
| 3 | Study market & competitors | Landing page comparison table (HFSS vs CST vs Feko vs AntennaForge) |
| 4 | Write value proposition | Landing page tagline: "Cloud antenna simulation — 90% less cost" |
| 5 | Test assumptions | Feedback page: 5 structured interview questions + Signup page segments by role |
| 6 | Validate WTP | Pricing page with dollar amounts + Free trial with credit card upsell path |
| 7 | Build simple MVP | Simulation page: 6 antenna types, essential params only, S-parameter sweep |
| 8 | North Star Metric | Dashboard header: "Simulations completed per week" with KPI card |
| 9 | Lean canvas | About page: full 9-box canvas rendered as cards |
| 10 | Customer feedback | Feedback page: "Build → Measure → Learn" cycle widget + triage process |
| 11 | Product roadmap | Roadmap page: Concept → Prototype → Alpha → Beta → Launch → Growth → Scale |
| 12 | Avoid feature creep | Simulate page toggle: "In MVP Scope / Future / Never Build" |
| 13 | Go-to-market strategy | Landing CTA funnel + Partners page distribution tiers |
| 14 | Targeted messages | Pricing page: each plan lists its target segment in the header |
| 15 | Sales funnel | Signup page: 3-step funnel (email → profile → password) + Dashboard retention tracking |
| 16 | CRM & analytics | Dashboard "Retention Status" funnel + In-app feedback collection |
| 17 | Revenue model | Pricing page: tiered subscription, add-ons, overage, education/nonprofit discounts |
| 18 | Partnerships | Partners page: 3 tiers — Distribution, Credibility, Technical |
| 19 | Team & culture | About page: team roles matrix + 6 operating culture principles |
| 20 | KPIs | Dashboard: 4 KPI cards + Analytics tab with business metrics |
